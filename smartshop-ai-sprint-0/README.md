# SmartShop AI

AI-assisted shopping application for students.

## Sprint 0
Project scaffolding only. This sprint establishes the repository structure, development configuration, and placeholder files.

## Planned stack
- Frontend: React + Vite
- Backend: Python + FastAPI
- Database: SQLite for development
- ORM: SQLAlchemy
- Authentication: JWT
- Styling: Bootstrap 5
- Version control: Git

## Project structure

```text
smartshop-ai/
├── backend/
│   ├── app/
│   │   ├── routes/
│   │   └── services/
│   ├── requirements.txt
│   └── .env.example
├── frontend/
├── .gitignore
└── README.md
```

## Prerequisites
Install:
- Node.js LTS
- Python 3.11+
- Git
- VS Code
